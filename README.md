# Dariya’s personal website

Open `dist/index.html` in your browser. No installation or build step is needed.

- Edit text and project cards in `dist/index.html`.
- Change the colors at the top of `dist/styles.css`.
- Add artwork files to `dist/images/`, then replace each `.art-placeholder` with an image. Update the gallery preview code in `script.js` to clone that image instead.
- Add project screenshots and links when ready. The Tkinter game illustration is a decorative example, not a screenshot of your work.
- Replace the Contact section’s coming-soon text with contact links you choose to share.

HTML provides the content, CSS provides the visual design, and the small JavaScript file handles filters, artwork previews, and the theme toggle. Google Fonts loads the optional typefaces; system fonts work offline.
